## 一、先分清三者

| 分类 | 主要位置 | 通俗理解 |
| --- | --- | --- |
| 后端 | `backend/` | 决定业务能不能办、金额怎么算、数据怎么保存，以及谁有权限操作。 |
| 前端 | `frontend/` | 接收点击和输入、向后端发送请求，并把返回的数据展示出来。 |
| UI | `frontend/src/views/`、`frontend/src/components/`、`frontend/src/*.css`、`frontend/public/images/` | 决定页面怎么排列、按钮和表格长什么样、使用什么颜色和图片。 |

**UI 是前端的一部分，本项目没有单独的 UI 工程。** 一个 `.vue` 文件通常同时包含交互逻辑和界面结构，不能简单地把整个文件只归为“逻辑”或“外观”。

`main.js` 的样式导入顺序是 **Element Plus 样式 → styles.css → workspace.css → refinement.css**。同等条件下后面的规则会覆盖前面的规则，但仍受选择器优先级、局部样式和 `!important` 影响。

**实际修改建议：** 改当前主题和全局视觉先查 `refinement.css`；只改某个页面的排列或字段，先查对应 `.vue` 文件，不要只改基础 CSS 后就认定一定生效。

## 五、改功能时找哪里

| 想修改的内容 | 优先查看 |
| --- | --- |
| 预约冲突、交还车条件、押金和结算规则 | 后端 `backend/src/main/java/com/yixing/order/RentalService.java`；前端 `frontend/src/views/Orders.vue`。 |
| 日租、里程、包月的计算公式 | 后端 `backend/src/main/java/com/yixing/pricing/PricingService.java`；前端 `frontend/src/views/Pricing.vue`。 |
| 客户只能查看和取消本人订单 | 后端 `backend/src/main/java/com/yixing/auth/SessionFilter.java`、`backend/src/main/java/com/yixing/customer/PortalController.java`；前端 `frontend/src/views/CustomerPortal.vue`。 |
| 登录、角色菜单和页面跳转 | 后端 `backend/src/main/java/com/yixing/auth/AuthController.java`、`backend/src/main/java/com/yixing/auth/SessionFilter.java`；前端 `frontend/src/views/Login.vue`、`frontend/src/main.js`、`frontend/src/App.vue`。 |
