# 易行租车：后端、前端与 UI 主要文件说明

本文按当前项目源码整理，帮助快速找到各功能的实现位置。

## 一、先分清三者

| 分类 | 主要位置 | 通俗理解 |
| --- | --- | --- |
| 后端 | `backend/` | 决定业务能不能办、金额怎么算、数据怎么保存，以及谁有权限操作。 |
| 前端 | `frontend/` | 接收点击和输入、向后端发送请求，并把返回的数据展示出来。 |
| UI | 前端中的 Vue 模板、CSS、组件和图片 | 决定页面怎么排列、按钮和表格长什么样、使用什么颜色和图片。 |

**UI 是前端的一部分，本项目没有单独的 UI 工程。** 一个 `.vue` 文件通常同时包含交互逻辑和界面结构，不能简单地把整个文件只归为“逻辑”或“外观”。

## 二、后端主要文件

后端 Java 源码集中在 `backend/src/main/java/com/yixing/`。

### 2.1 启动与接口

| 文件 | 主要作用 |
| --- | --- |
| [Application.java](../backend/src/main/java/com/yixing/Application.java) | 后端启动入口，启动 Spring Boot 应用。 |
| [web/ApiController.java](../backend/src/main/java/com/yixing/web/ApiController.java) | 管理端主要接口入口，将车辆、客户、订单等请求转交给对应业务服务。 |
| [customer/PortalController.java](../backend/src/main/java/com/yixing/customer/PortalController.java) | 客户端接口，处理本人资料、选车数据、预约和取消预约，并限制只能操作本人订单。 |
| [auth/AuthController.java](../backend/src/main/java/com/yixing/auth/AuthController.java) | 登录、退出、查询当前登录身份及修改密码。 |
| [web/FileController.java](../backend/src/main/java/com/yixing/web/FileController.java) | 车辆图片上传和读取，以及备份文件下载、恢复文件上传。 |

### 2.2 核心业务

| 文件 | 主要作用 |
| --- | --- |
| [order/RentalService.java](../backend/src/main/java/com/yixing/order/RentalService.java) | **租赁业务核心。** 处理预约、租期冲突、收款、交车、还车、结算和取消；通过事务和行锁协调数据修改。 |
| [pricing/PricingService.java](../backend/src/main/java/com/yixing/pricing/PricingService.java) | 统一计算按天、按里程和包月租金，供预约试算和实际还车计费使用。 |
| [vehicle/VehicleService.java](../backend/src/main/java/com/yixing/vehicle/VehicleService.java) | 车辆档案新增、修改、启停，以及里程、门店等字段的业务限制。 |
| [customer/CustomerService.java](../backend/src/main/java/com/yixing/customer/CustomerService.java) | 客户建档、修改资料，校验限制租赁标记和驾驶证有效期。 |
| [dispatch/DispatchService.java](../backend/src/main/java/com/yixing/dispatch/DispatchService.java) | 创建、开始、完成及取消调度，检查预约冲突并更新车辆所属门店。 |
| [maintenance/MaintenanceService.java](../backend/src/main/java/com/yixing/maintenance/MaintenanceService.java) | 维修保养工单、开工和完工、车辆维修状态，以及日期和里程提醒。 |
| [report/ReportService.java](../backend/src/main/java/com/yixing/report/ReportService.java) | 汇总经营收入、订单数量、维修费用和车辆使用情况；这里是系统报表功能，不是实训报告文件。 |
| [system/SystemService.java](../backend/src/main/java/com/yixing/system/SystemService.java) | 账号、门店、价格和系统参数管理，以及数据备份恢复。 |

**阅读重点：** `Controller` 看“有哪些接口、请求交给谁”，`Service` 看“业务具体怎么处理”。本项目多数业务规则在 `Service` 中，不在接口方法里。

### 2.3 登录权限与公共处理

| 文件 | 主要作用 |
| --- | --- |
| [auth/SessionFilter.java](../backend/src/main/java/com/yixing/auth/SessionFilter.java) | 在接口处理前校验会话、账号状态、请求来源和角色权限。 |
| [auth/Access.java](../backend/src/main/java/com/yixing/auth/Access.java) | 取得当前操作人、检查管理员身份、登记操作日志。 |
| [auth/AccountService.java](../backend/src/main/java/com/yixing/auth/AccountService.java) | 客户注册、账号格式和重复校验，同时创建客户档案与登录账号。 |
| [auth/AccountUpgrade.java](../backend/src/main/java/com/yixing/auth/AccountUpgrade.java) | 启动时兼容旧账号表结构和旧业务人员角色。 |
| [common/Values.java](../backend/src/main/java/com/yixing/common/Values.java) | 统一读取、转换和检查字符串、整数、金额、日期等输入。 |
| [common/BusinessException.java](../backend/src/main/java/com/yixing/common/BusinessException.java) | 业务条件不满足时中止操作，例如租期冲突或押金未收齐。 |
| [common/ApiErrors.java](../backend/src/main/java/com/yixing/common/ApiErrors.java) | 将常见异常转换成前端可以显示的错误消息。 |

### 2.4 数据访问与数据库配置

| 文件 | 主要作用 |
| --- | --- |
| [data/Store.java](../backend/src/main/java/com/yixing/data/Store.java) | 业务服务共用的数据访问入口，提供查询、新增、修改和行锁操作。 |
| [data/DataMapper.java](../backend/src/main/java/com/yixing/data/DataMapper.java) | MyBatis 数据库映射，执行查询和写入等 SQL。 |
| [data/Statements.java](../backend/src/main/java/com/yixing/data/Statements.java) | 根据要写入的字段生成新增和修改 SQL，实际数据通过参数绑定传入。 |
| [data/DemoData.java](../backend/src/main/java/com/yixing/data/DemoData.java) | 空库首次启动时生成课程演示账号、车辆、客户、订单等数据。 |
| [application.properties](../backend/src/main/resources/application.properties) | 基础运行配置，例如后端端口、会话、上传限制和默认数据源。 |
| [application-mysql.properties](../backend/src/main/resources/application-mysql.properties) | 启用 MySQL 配置时使用的数据源及建表脚本位置，连接信息可由环境变量传入。 |
| [schema-mysql.sql](../backend/src/main/resources/schema-mysql.sql) | MySQL 模式启动时加载的建表脚本；修改表结构时重点检查这里。 |
| [backend/pom.xml](../backend/pom.xml) | Java 版本、后端依赖和 Maven 构建配置。 |

**注意：** 源码包 `backend/src/main/java/com/yixing/data/` 与根目录运行数据 `data/` 不是同一个目录。前者是代码，后者是本地数据库和运行配置，不要混淆。

## 四、UI 主要文件

### 4.1 全局样式

| 文件 | 主要控制什么 |
| --- | --- |
| [src/styles.css](../frontend/src/styles.css) | 基础样式，包括页面外壳、表格、表单、卡片和小屏布局等基础规则。 |
| [src/workspace.css](../frontend/src/workspace.css) | 在基础样式上调整工作空间的字号、间距、控件和各业务区域布局。 |
| [src/refinement.css](../frontend/src/refinement.css) | 当前视觉细化层，包含主题变量、侧栏外观、字体、指标数字、表格和部分页面布局。 |
| [views/Login.vue](../frontend/src/views/Login.vue) | 除登录逻辑和模板外，还包含登录页自己的局部样式。 |
| [docs/UI设计规范.md](../docs/UI设计规范.md) | 记录设计方向和规范，用来理解风格；它是说明文档，不会直接改变页面。 |

`main.js` 的样式导入顺序是 **Element Plus 样式 → styles.css → workspace.css → refinement.css**。同等条件下后面的规则会覆盖前面的规则，但仍受选择器优先级、局部样式和 `!important` 影响。

**实际修改建议：** 改当前主题和全局视觉先查 `refinement.css`；只改某个页面的排列或字段，先查对应 `.vue` 文件，不要只改基础 CSS 后就认定一定生效。

## 五、改功能时找哪里

| 想修改的内容 | 优先查看 |
| --- | --- |
| 预约冲突、交还车条件、押金和结算规则 | 后端 `RentalService.java`；对应交互在前端 `Orders.vue`。 |
| 日租、里程、包月的计算公式 | 后端 `PricingService.java`；试算输入和展示在前端 `Pricing.vue`。 |
| 客户只能查看和取消本人订单 | 后端 `SessionFilter.java`、`PortalController.java`；对应页面在 `CustomerPortal.vue`。 |
| 登录、角色菜单和页面跳转 | 后端 `AuthController.java`、`SessionFilter.java`；前端 `Login.vue`、`main.js`、`App.vue`。 |
| 全站颜色、字号、侧栏、表格外观 | 前端 `refinement.css`，结合 `workspace.css`、`styles.css` 检查覆盖关系。 |
| 某个页面的按钮、字段和排列 | 对应 `views/*.vue`；共用表单结构还要看 `FormDialog.vue`。 |
| 工作台和统计图表 | 前端 `Dashboard.vue`、`Reports.vue`、`ChartPanel.vue`；经营统计口径看后端 `ReportService.java`。 |
| 车辆照片、参考图和图片回退 | 前端 `VehicleThumbnail.vue`、`vehiclePhotos.js`、`vehiclePhotoCatalog.js`；上传接口看后端 `FileController.java`。 |
| 数据表结构与 MySQL 连接 | 后端 `schema-mysql.sql`、`application-mysql.properties`；本地数据库启动看 `scripts/local_mysql.py`。 |

## 六、用“创建预约”串起来看

1. 用户在前端 `Orders.vue` 或 `CustomerPortal.vue` 中填写租期、车辆等信息。
2. `api.js` 将请求发送到后端接口。
3. `SessionFilter.java` 检查是否登录及是否有权限。
4. 管理端请求进入 `ApiController.java`，客户端请求进入 `PortalController.java`。
5. `RentalService.java` 检查驾驶资格、车辆状态和租期冲突，并调用 `PricingService.java` 计算预计租金。
6. `Store.java` 通过 `DataMapper.java`、`Statements.java` 将订单写入数据库。
7. 前端通过 `store.js` 刷新数据，更新订单列表和详情。

**记忆方式：页面收集输入，接口接收请求，业务服务做判断，数据层负责保存。**

## 七、后端学习的推荐顺序

1. `ApiController.java`：先了解系统提供哪些业务接口。
2. `RentalService.java`：重点理解预约到结算的完整过程，以及事务和加锁位置。
3. `PricingService.java`：理解三种计费公式和金额计算。
4. `SessionFilter.java`、`PortalController.java`：理解登录权限与客户数据隔离。
5. `Store.java`、`DataMapper.java`、`Statements.java`：理解业务数据如何进入数据库。
6. `DispatchService.java`、`MaintenanceService.java`：理解车辆状态如何与调度、维修联动。
7. `ReportService.java`、`SystemService.java`：理解统计口径、账号管理和备份恢复。

需要对照测试时，可以查看 [RentalWorkflowTest.java](../backend/src/test/java/com/yixing/RentalWorkflowTest.java)、[CustomerPortalTest.java](../backend/src/test/java/com/yixing/CustomerPortalTest.java) 和 [PricingTest.java](../backend/src/test/java/com/yixing/PricingTest.java)。
