# 易行租车 UI 设计规范

更新日期：2026-10-29。以下规范优先于此前的暖白墨黑版，按本次用户批注调整。

## 当前方向

- 基础色为清透蓝白 `#f7f9fc` 与白色内容面，正文使用深海军蓝 `#122440`，辅助信息使用 `#4d607a`，避免大面积低对比灰雾效果。
- 侧栏为暖橙棕遮罩叠加项目现有汽车与森林摄影，遮罩不透明度由上至下约为 76%、72%、65%，比此前蓝灰版更通透。选中项采用暖白底与深橙文字、细橙色定位线；滚动条和底部信息区同步使用暖色。
- 主操作为明亮橙 `#cf4b0a` 配白色文字；车辆和订单状态继续分别使用蓝、青绿、紫、黄褐与灰，不把所有状态染为品牌色。
- 中文使用本机 Microsoft YaHei UI / PingFang SC，指标数字使用 Bahnschrift / DIN Alternate 回退。数字采用等宽数码与明确的字号、字重区分。
- 顶栏与侧栏底部使用局部背景模糊、半透明面和高光边线形成轻玻璃质感；表格、表单及正文保持实色清晰，不对内容层施加模糊。

## 文字与数字提亮

- 指标数字分别使用活力橙 `#e85d0c`、亮蓝 `#2563eb`、青绿 `#008568`、亮紫 `#7c3aed`，保持统一数码字体和较高字重；大号数字使用鲜明色，小字号文字与操作保持更深的高对比配色。
- 正文保持清晰深蓝，不通过减淡文字来提亮。背景调整为更通透的蓝白，收入图表使用明亮橙与蓝，状态标签独立使用语义色。
- 保持页面结构、汽车摄影、登录全幅背景及业务数据不变。

## 业务展示

- 管理端与客户端共享品牌和基础组件，路由、导航与数据权限独立。客户端仅显示选车、本人订单、个人资料。
- 车辆名称、车牌与图片在列表、详情、车辆选择器、养护、调度、报表、客户历史、最近订单等位置使用统一图文展示。
- 18 款现有车型素材继续使用透明、前侧朝左的参考照片。按素材坐标在展示层遮挡示意车牌，不破坏原文件与来源记录；业务车牌仍在文字中准确显示。
- 统计报表车辆使用合为单一排行，提供时长、次数、已结算收入切换，指标口径随说明展示；每日明细最新日期在上。
- 工单提醒只在有记录时出现，创建与开始按钮使用主按钮规范，工单开始后移除该车辆的提醒。
- 租金试算只显示当前计费方式所需输入；包月保留既有 30 天计费月语义，并明确起止日期。
- 小屏表格保留独立横向滚动，不扩张页面；排行条在小屏隐藏纯视觉长度轨道，保留图片、车辆和数值。

## 实现入口

- `frontend/src/refinement.css` 为本轮样式覆盖；不移除原有基础样式，以减少业务布局回归风险。
- `VehicleIdentity.vue` 组合统一图文；`VehicleThumbnail.vue` 负责来源回退、图片错误与车牌遮挡。
- 焦点轮廓、原生表单标签、图片替代文本和减少动态效果设置继续保留。
